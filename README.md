# k3s Playground

Projet portfolio dédié à l'apprentissage approfondi de Kubernetes (k3s).

Pipeline de traitement d'images asynchrone (upload → resize/filtre → stockage),
conçu pour exercer l'ensemble des objets Kubernetes fondamentaux : Deployment,
StatefulSet, Job, CronJob, DaemonSet, ConfigMap, Secret, PVC, Ingress,
NetworkPolicy, RBAC, HPA.

Voir `CAHIER_DES_CHARGES.pdf` pour le détail complet.
